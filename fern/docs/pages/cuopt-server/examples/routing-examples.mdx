The `data` argument to `get_optimized_routes` may be a dictionary of the format shown in [Get Routes Open-API spec](../../open-api). It may also be the path of a file containing such a dictionary as JSON or written using the Python *msgpack* module. A JSON file may optionally be compressed with zlib. More details on the responses can be found under the responses schema in ["get /cuopt/request" and "get /cuopt/solution" API spec](../../open-api).
