The **NVIDIA cuOpt self-hosted server** is a **REST** (HTTP/JSON) service for integrations that speak HTTP. Use [Quick Start](quick-start) for deployment, [Index](server-api/index) for the API, and [Index](client-api/index) for clients (including cuopt-sh-client).

For **gRPC remote execution** (Python, C API, `cuopt_cli`, or custom clients to `cuopt_grpc_server`), see [Index](../cuopt-grpc/index) — it uses a different protocol and is not part of the HTTP REST surface.
