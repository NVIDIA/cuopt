# Quickstart Guide

cuopt\_cli is built as part of the libcuopt package. Choose your install method below; the selector is pre-set for the CLI (it uses the same libcuopt install). Copy the command and run it in your environment. See [Install](../install) for all interfaces and options.

## Installation

<div id="cuopt-install-selector" data-default-iface="cli"></div>

To see all available options and their descriptions:

``` bash
cuopt_cli --help
```

This will display the complete list of command-line arguments and their usage:

``` text
# File not found: cuopt-cli-help.txt
```

Please refer to [Convex Settings](../convex-settings) and [Mip Settings](../mip-settings) for more details on default values and other options.
