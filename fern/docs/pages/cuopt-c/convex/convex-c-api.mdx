## Optimization Problem

An optimization problem is represented via a `cuOptOptimizationProblem`.

<!-- symbol: cuOptOptimizationProblem -->
<!-- /symbol -->

Optimization problems can be created, loaded, or written via the following functions.

<!-- symbol: cuOptReadProblem -->
<!-- /symbol -->

<!-- symbol: cuOptWriteProblem -->
<!-- /symbol -->

<!-- symbol: cuOptCreateProblem -->
<!-- /symbol -->

<!-- symbol: cuOptCreateRangedProblem -->
<!-- /symbol -->

<!-- symbol: cuOptCreateQuadraticProblem -->
<!-- /symbol -->

<!-- symbol: cuOptCreateQuadraticRangedProblem -->
<!-- /symbol -->

<Warning>
`cuOptCreateQuadraticProblem` and `cuOptCreateQuadraticRangedProblem` are deprecated.
Prefer `cuOptCreateProblem` or `cuOptCreateRangedProblem` followed by `cuOptSetQuadraticObjective`.
</Warning>

For problems with quadratic objectives, first create a problem, and then use:

<!-- symbol: cuOptSetQuadraticObjective -->
<!-- /symbol -->

For problems with quadratic constraints, first create a problem, and then use:

<!-- symbol: cuOptAddQuadraticConstraint -->
<!-- /symbol -->

<Note>
Support for quadratic constraints is currently in **beta**.
`cuOptAddQuadraticConstraint` supports three types of quadratic constraints:
convex quadratic constraints of the form `x^T Q x + d^T x &lt;= alpha` where `H=(Q+Q^T)/2`
is a symmetric positive semidefinite matrix; second-order cone constraints of the form
`sum x_i^2 &lt;= x_0`, `x_0 >= 0`; and rotated second-order cone constraints.
Only `CUOPT_LESS_THAN` and `CUOPT_GREATER_THAN` sense is supported.
</Note>

An optimization problem must be destroyed with the following function.

<!-- symbol: cuOptDestroyProblem -->
<!-- /symbol -->
