# Quickstart Guide

NVIDIA cuOpt provides C API for LP, QP and MILP. This section will show you how to install cuOpt C API and how to use it to solve LP, QP and MILP problems.

## Installation

Choose your install method below; the selector is pre-set for the C API (libcuopt), which also provides `cuopt_cli`. Copy the command and run it in your environment. See [Install](../install) for all interfaces and options.

<Note>
Visit the [Installation Guide](install) to choose your interface and install method.
</Note>

Please visit examples under each section to learn how to use the cuOpt C API.
